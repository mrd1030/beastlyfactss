# Beastfile candidates from Beastle

The Beastle bonus round uses these animals as hand-picked wrong answers
(src/lib/data/beastle/decoys.js, DECOY_OVERRIDES). None of them has a pool
entry, so a player who picks one gets no field-journal page. Each is a
candidate for a Beastfile. When one gets a Beastfile and joins the Beastle
pool, the round picks up its pool entry by name automatically. Remove it from
this list when that happens.
